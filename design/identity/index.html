Usage and portfolio integration

Small sizes

Below 48px, use the heavier single-color symbol. Do not use the outlined version below 48px or the single-color symbol below 32px.

Optional motion

Move the cursor by one grid step on hover or focus, then return it. Keep the outlined panels stationary. Use 200ms feedback and a static reduced-motion state.

Header asset

Usage and portfolio integration

Small sizes

Use the single-color silhouette below 32px. Its open counter and broad diagonal remain the defining elements; stop at 24px.

Optional motion

Shift the blue terminal by at most one quarter of its width on hover or focus. Keep the main silhouette fixed. Use 200ms feedback and a static reduced-motion state.

Usage and portfolio integration

Small sizes

Use the rails-only symbol below the wordmark minimum. For a single-color application, retain both rails and the terminal square; stop at 24px.

Optional motion

Reveal the second rail and terminal together in a short opacity transition. Keep the lettering still. Use 200ms feedback and a static reduced-motion state.
